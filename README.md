# Million Cloud: test builds

Android test builds of the Million Cloud mobile app. The app is read-only: it shows your company's reports and
dashboard, and can't change any data. It connects to the live Million Cloud server, so sign in with your normal
Million Cloud account.

## Install

1. On your Android phone, open the
   [latest release](https://github.com/sheng0716/million-cloud-releases/releases/latest) and download the `.apk`
   file.
2. Open the downloaded file. If Android blocks it, allow "Install unknown apps" for your browser, then open it
   again.
3. To update, install the newer APK over the old one. You don't need to uninstall first.
